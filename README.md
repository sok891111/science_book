# 마법과학 AR — QR 영상 뷰어

책 속 **QR 코드**를 앱 안에서 카메라로 비추면, 그 화의 **과학 영상**이 앱 안에서 바로 재생되는 웹앱이에요.
앱스토어 없이 **웹(PWA)** 으로 동작하고, 아이패드 **"홈 화면에 추가"** 로 아이콘처럼 쓸 수 있어요.

---

## 📁 폴더 구성

```
index.html          # 앱 화면
app.js              # 카메라 스캔 + 영상 재생 로직
config.js           # ★ 영상 목록 (여기만 고치면 됨)
styles.css          # 디자인
manifest.json       # 홈 화면 아이콘 설정 (PWA)
service-worker.js   # 오프라인 캐시(껍데기)
icons/              # 앱 아이콘
qr/                 # QR 코드 이미지 + 인쇄용 모음 페이지
videos/             # mp4를 직접 쓸 경우 여기에 넣기
```

---

## ▶️ 빠르게 테스트하기 (내 맥에서)

카메라는 **localhost** 또는 **https** 에서만 켜져요. 맥에서 바로 확인하려면:

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 **http://localhost:8000** 접속 →
"카메라 켜기" → 화면에 `qr/qr-demo.png` 를 비추면 **데모 영상**이 재생돼요.

> 📱 **아이패드 실제 테스트**는 https 주소가 필요해요 → 아래 "배포" 참고.

---

## 🎬 영상 추가/교체하는 법 (`config.js`)

QR 코드 안에는 `ch1`, `ch2` 같은 **코드만** 들어있어요.
앱은 `config.js` 의 표를 보고 영상을 찾아 틀어줍니다. **그래서 영상이 바뀌어도 QR/책은 그대로 두면 돼요.**

### 유튜브 영상 연결
1. 유튜브에 영상 업로드 (**'미등록'** 추천 — 검색에 안 뜸)
2. 주소가 `https://youtu.be/AbCdEf12345` 라면, 뒤의 `AbCdEf12345` 가 **영상 ID**
3. `config.js` 에서 해당 화의 `id` 를 바꾸기:
   ```js
   ch2: { title: "2화 · 비행기는 무슨 도술이냐?!", type: "youtube", id: "AbCdEf12345" },
   ```

### mp4 직접 연결 (추천영상 0)
1. mp4 파일을 `videos/` 폴더에 넣기 (예: `videos/ch3.mp4`)
2. `config.js` 에 추가:
   ```js
   ch3: { title: "3화 · 배는 왜 안 가라앉지?!", type: "mp4", src: "videos/ch3.mp4" },
   ```

### 새 QR 코드 만들기 (새 화 추가 시)
```bash
python3 - <<'PY'
import qrcode
code = "ch3"   # ← 원하는 코드로 변경
qr = qrcode.QRCode(box_size=12, border=3)
qr.add_data(code); qr.make(fit=True)
qr.make_image(fill_color="#0b1f3a", back_color="white").save(f"qr/qr-{code}.png")
print("생성:", f"qr/qr-{code}.png")
PY
```

## 🖨️ QR 코드 책에 넣기

- `qr/인쇄용_QR모음.html` 을 브라우저로 열어 인쇄하면 한 장에 모아 볼 수 있어요.
- 또는 `qr/qr-ch2.png` 같은 이미지를 만화 페이지에 직접 합성.
- **무광 인쇄 / 최소 3cm 이상 / 너무 어둡지 않은 곳** 에서 잘 인식돼요.

## 🚀 배포 (아이패드에서 쓰려면 — HTTPS 필요)

### 방법: GitHub Pages (무료, HTTPS 자동)
1. GitHub에 새 저장소 만들기
2. 앱 파일들을 저장소 루트에 업로드(push)
3. 저장소 **Settings → Pages** 에서 브랜치 지정 → 잠시 후 `https://...github.io/...` 주소 생성
4. 아이패드 사파리로 그 주소 접속 → **공유 → "홈 화면에 추가"** → 아이콘 완성!

> Netlify, Cloudflare Pages, Vercel 같은 무료 서비스도 동일하게 가능해요.

## 📱 아이패드 사용 순서 (아이/가족용)

1. 홈 화면의 **마법과학** 아이콘 터치
2. **카메라 켜기** 버튼 누르기 (처음 한 번 카메라 권한 허용)
3. 책의 **QR 마크**를 화면 가운데 네모에 맞추기
4. **▶ 재생** 버튼 누르면 영상 시작! (영상이 끝나면 자동으로 다시 카메라로 돌아가요)

---

## ⚠️ 자주 묻는 문제

| 증상 | 해결 |
|------|------|
| 카메라가 안 켜짐 | https(또는 localhost) 주소인지 확인 / 카메라 권한 허용 |
| 소리가 안 남 | iOS는 **▶ 재생 버튼을 직접 눌러야** 소리가 나요 (정상) |
| 'ch1 영상을 찾을 수 없어요' | `config.js` 에 그 코드가 있는지, 유튜브 id를 넣었는지 확인 |
| 유튜브 끝에 추천영상 보임 | 영상 종료 시 자동으로 카메라로 돌아가게 되어 있음 / 완전 차단은 mp4 직접 재생 사용 |
